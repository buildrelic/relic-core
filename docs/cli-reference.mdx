Every command is a subcommand of `relic` ([`cli.py`](https://github.com/buildrelic/relic-core/blob/main/packages/relic-cli/src/relic/cli.py)). Run
`uv run relic --help` for the live list, or `uv run relic <command> --help` for one
command. The CLI prints `--help` when given no arguments.

Commands group into the capture and memory side, the skills side, diagnostics, and
two stubs that land in later phases.

## Global options

- `--verbose` / `-v`: drop logging to debug level. Goes before the command:
  `relic --verbose ingest --repo owner/name`. Logs go to stderr, results to
  stdout, so `relic recall "q" > out.txt` keeps logs off the file.

## Capture and memory

### relic ingest

Pull merged PRs, reviews, and issues into the graph.

```
relic ingest --repo OWNER/NAME [--limit N] [--months M] [--bulk] [--fresh] [--no-progress] [--no-load]
```

- `--repo` (required): the `owner/name` to ingest. Anything without a `/` exits 2.
- `--limit` (optional): cap merged PRs and issues pulled, most recent first.
- `--months` (optional, default 12): how many months of history to backfill. PRs
  merged and issues updated within the window are pulled.
- `--bulk` (optional): load via batched `add_episode_bulk` for a faster backfill
  (experimental; sequential is the default). Also set by `BULK_LOAD`.
- `--fresh` (optional): ignore the checkpoint and reload every episode. Pair it
  with clearing the repo's graph, or you get duplicates.
- `--no-progress` (optional): disable the live progress bar. It already turns off under `--verbose` and when stderr is not a terminal.
- `--no-load` (optional): run only the fast, no-LLM half (fetch, map, raw store,
  spool) and stop. No FalkorDB or `OPENAI_API_KEY` needed. The episodes are left on
  the spool under `./data/spool/<group_id>/`; run `relic load` to extract them.

An ingest has two halves: a fast deterministic capture and a slow LLM extraction.
The default runs both. `--no-load` runs the first and hands off to `relic load`, so
the expensive step can run later, on a schedule, or one batch at a time.

A full ingest needs a GitHub token, `OPENAI_API_KEY`, and a running FalkorDB; a
`--no-load` capture needs only a GitHub token (no graph, no OpenAI). Pulls Linear too
when `LINEAR_API_KEY` is set. Resumable: a re-run skips episodes already landed
(the per-repo checkpoint under `./data/ingest/`). See [Ingestion](/ingestion).

Exit codes: `0` on success (including a no-op re-run where everything was already
loaded, and a `--no-load` capture), `2` for a malformed `--repo`, `1` when the graph
is unreachable or the run loaded nothing because every episode failed.

```bash
uv run relic ingest --repo astral-sh/uv --limit 20
uv run relic ingest --repo astral-sh/uv --no-load   # capture only, extract later
uv run relic --verbose ingest --repo astral-sh/uv   # debug logging
```

### relic load

Extract spooled episodes into the graph: the LLM-heavy half of ingest, run on demand.

```
relic load --repo OWNER/NAME [--limit N] [--bulk] [--fresh] [--no-progress]
```

- `--repo` (required): the `owner/name` whose spooled episodes to extract. Reads
  `./data/spool/<group_id>/`, written by a prior `relic ingest`. Anything without a
  `/` exits 2.
- `--limit` (optional): extract at most N not-yet-loaded episodes, for case-by-case
  loading. Re-run to drain more.
- `--bulk` (optional): load via batched `add_episode_bulk`. Also set by `BULK_LOAD`.
- `--fresh` (optional): ignore the checkpoint and reload every spooled episode. Pair
  it with clearing the repo's graph, or you get duplicates.
- `--no-progress` (optional): disable the live progress bar.

Needs `OPENAI_API_KEY` and a running FalkorDB, but no GitHub token: it reads the
spool, not the network. Resumable and idempotent: it skips episodes the checkpoint
already records, so a re-run only extracts what is new. An empty spool is a no-op.

Exit codes: `0` on success (including an empty spool and a no-op re-run), `2` for a
malformed `--repo`, `1` when the graph is unreachable or every episode failed.

```bash
uv run relic ingest --repo astral-sh/uv --no-load   # capture
uv run relic load --repo astral-sh/uv --limit 5     # extract the first 5, on demand
uv run relic load --repo astral-sh/uv               # extract the rest
```

### relic recall

Recall facts from the memory graph, with their sources.

```
relic recall "QUERY" [--repo OWNER/NAME] [--num-results N]
```

- `query` (argument, required): what to recall.
- `--repo` (optional): scope to a repo's graph. Defaults to `TARGET_REPO`.
- `--num-results` (optional, default 10): max facts to return.

```bash
uv run relic recall "who usually reviews auth changes?"
```

### relic query

Find people connected to work matching the text (search first, Cypher fallback).

```
relic query "TEXT" [--repo OWNER/NAME]
```

- `text` (argument, required): the query string.
- `--repo` (optional): scope to a repo's graph. Defaults to `TARGET_REPO`.

Prints each person, relation, fact, profile URL, and source episodes,
de-duplicated by name.

### relic eval

Score recall against a gold set by checking whether it cites the PR or issue that
holds each answer. A malformed or unreadable gold set exits 1.

```
relic eval [--path PATH] [--num-results N] [--json PATH]
```

- `--path` (optional, default `eval/github_recall.json`): the gold set JSON.
- `--num-results` (optional, default 10): facts per question.
- `--json` (optional): also write the run as machine-readable JSON to this path, alongside the stdout summary.

```bash
uv run relic eval
uv run relic eval --path eval/my-set.json
```

## Skills

### relic register

Load a `SkillIR` JSON file into the registry as a skill (the manual authoring
path). Invalid JSON exits 1.

```
relic register PATH
```

```bash
uv run relic register examples/skills/pr-review-routing.json
```

### relic list

List registered skills, optionally filtered by status.

```
relic list [--status draft|verified|deprecated]
```

### relic show

Show a skill's rendered `SKILL.md`, or its raw `SkillIR` JSON. Unknown id exits 1.

```
relic show SKILL_ID [--json]
```

### relic verify

Promote a draft skill to verified and stamp `last_verified_at`. Unknown id or a
deprecated skill exits 1.

```
relic verify SKILL_ID
```

### relic deprecate

Mark a skill deprecated so it stops being emitted or served. Unknown id exits 1.

```
relic deprecate SKILL_ID
```

### relic emit

Write verified skills and a catalog index to a target repo's `.claude/skills/`,
and remove the files of any skill since deprecated.

```
relic emit --repo /path/to/target-repo
```

### relic catalog

Print a browsable markdown index of verified skills to stdout.

```
relic catalog
```

### relic serve

Serve verified skills and memory recall as MCP tools over stdio. The one
long-running command. See [Skills](/skills).

```
relic serve [--repo OWNER/NAME]
```

- `--repo` (optional): scope `recall_memory` to a repo's graph. Defaults to
  `TARGET_REPO`. Recall reads one repo's graph, so without a repo set here or in
  `TARGET_REPO` it reads the default graph and returns nothing for memory you
  ingested under a repo.

## Diagnostics

### relic doctor

Report registry, graph, and key status for this setup. Reads only, changes
nothing, never raises. See [Configuration](/configuration).

```
relic doctor
```

## Stubs (later phases)

### relic resolve

Unify people across GitHub and Linear into single `Person` nodes. Phase 3. Prints
"not implemented yet" and exits 1.

### relic compile

Detect a procedure and compile it into a grounded `SkillIR`. Phase 4. Prints "not
implemented yet" and exits 1.

```
relic compile --skill ARCHETYPE
```
